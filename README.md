# esp8266_experiments

Use I2C vs. SPI
Logic Analyzer, Oscilloscope

ESP8266 protocol evaluation project comparing I2C and SPI communication using two identical BMP280 sensors. The repository contains the firmware and hardware testing notes to benchmark data throughput, measure protocol overhead, and analyze signal integrity using an oscilloscope and logic analyzer. Testing focus areas include comparing I2C pull-up resistor rise times, pushing clock speed boundaries to observe waveform distortion, and evaluating bus recovery behavior during simulated communication faults.
